# Privacy Policy

## Overview

AI Agent Automation is an open-source, local-first platform for building and executing AI-powered workflows. This Privacy Policy explains what data may be collected, how it is used, and how users retain control over their data.

---

## Data We Collect

Depending on how the platform is configured, the following information may be stored:

- User account and authentication information
- Workflow definitions and execution history
- Agent memory created during workflow execution
- Uploaded documents and generated document embeddings
- Application settings and configuration
- System logs and error logs
- Optional telemetry data (if enabled)

---

## Purpose of Data Collection

The collected data is used to:

- Authenticate users
- Execute and manage AI workflows
- Store workflow history and execution results
- Improve agent memory and document retrieval
- Monitor application performance
- Troubleshoot errors and system issues

---

## Third-Party AI Providers

The platform can integrate with external AI providers, including:

- OpenAI
- Google Gemini
- Groq
- Hugging Face
- Ollama (self-hosted)

When these providers are configured, prompts and related request data may be processed according to the privacy policies of the selected provider.

---

## Self-Hosted Deployments

AI Agent Automation is designed to support self-hosted deployments.

In self-hosted environments, the organization or individual deploying the platform is responsible for managing stored data, security, backups, and compliance requirements.

---

## Data Retention

Data is retained for as long as it is required by the deployed instance.

Retention policies may vary depending on the deployment configuration and administrator preferences.

---

## Data Deletion

Users or administrators can remove:

- Uploaded documents
- Agent memories
- Workflow definitions
- Execution logs (where supported)
- User-generated data

The availability of deletion features depends on the deployment configuration.

---

## Security Measures

The platform includes features intended to improve security, such as:

- Authentication mechanisms
- Access controls
- Local-first deployment support
- Secure API integrations
- Logging for monitoring and debugging

Administrators are responsible for securing their deployment environment.

---

## User Rights

Depending on local laws and deployment configuration, users may have the ability to:

- Request access to stored information
- Request correction of inaccurate information
- Request deletion of stored information
- Control optional telemetry settings

---

## Compliance Considerations

AI Agent Automation provides privacy-related features that can assist organizations in meeting their own compliance requirements.

However, compliance with regulations such as GDPR, CCPA, or other applicable laws depends on how the platform is deployed and managed.
